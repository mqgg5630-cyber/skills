# 修订说明（2026-10-22）

本版修了两处与外部表对不上的地方。两处都不是数据错误，是统计口径不一致。

## 一、第一处：MAG 记录数与分析数

外部表统计**与发酵样品关联的全部 MAG 记录**，不做质量与 SGB 过滤；报告正文统计**通过筛选、进入分析的 MAG**。两者相差 276 条：

| 项目 | 外部表 | 原报告 | 本版 |
| --- | --- | --- | --- |
| 发酵 MAG | 15,722 | 15,446 | 15,722（记录）/ 15,446（分析） |
| 细菌 | 14,676 | 14,598 | 14,676 / 14,598 |
| 真核 | 947 | 848 | 947 / 848 |
| 未分类 | 99 | 未列 | 99 |

276 条 = 78 个原核（污染 ≥5% 或完整度 <50%）+ 99 个真核（质量不达标）+ 99 条 superkingdom 为空的记录。
逐类核对：样品数、MAG 记录数、细菌数三项，10 个类别全部为 0 差异（`tables/23_与外部汇总表核对.csv`）。

## 二、第二处：type 层的样品数

原 type 表（表 20、附表 B）的样品数是按 MAG 反查得到的，漏掉了没有可用 MAG 的样品，所以偏小：

| 类型 | 外部表 | 原报告 | 本版 |
| --- | --- | --- | --- |
| cheese | 1,857 | 1,748 | 1,857 |
| water_kefir | 388 | 386 | 388 |
| kefir | 293 | 266 | 293 |
| whey | 85 | 71 | 85 |
| salami | 80 | 77 | 80 |

同时 type 表只列了 91 个类型，实际发酵样品覆盖 101 个 type，没有 MAG 的类型被整行丢掉了。
本版改为：样品数、数据集数、国家数一律取元数据；MAG 相关列仍取分析集，并单列"MAG 记录数"与"有关联MAG样品数"两列。
类别表（表 7）此前就是元数据口径，未受影响。

## 三、本版改动清单

1. 类别表同时给出"MAG 记录"与"纳入分析"，新增 1.4 节与表 5 逐项核对。
2. type 表改为 101 行、元数据口径，新增"MAG 记录数""有关联MAG样品数"两列。
3. 附表 B 改为按样品量排序，增加 MAG 记录列。
4. 新增 `tables/23_与外部汇总表核对.csv`，Excel 增加"与外部表核对"工作表。
5. 补样品层面对齐：3,293 份发酵样品中 3,073 份有 MAG，220 份没有（乳制品 171 份）。
6. 总体指标表拆成"发酵 MAG 记录 15,722"与"其中纳入分析 15,446"两行。
7. "每样品平均 MAG 数"的分母改为有关联 MAG 的样品数。

## 四、未受影响的部分

SGB（1,142）、属种组成、alpha 多样性、益生菌各口径（42 / 4,925 / 6,385 / 1,869 / 292）、antiSMASH 输入与 BGC 估算都没有变化，这些本来只依赖纳入分析集。

antiSMASH 仍未实际运行（无 MAG 序列、无算力），相关表为文献推算。

外部表也在本文件夹内（`cFMD_全发酵食品统计汇总.xlsx`），可直接对照。
