# Skills 图解教程 - 快速开始指南

## 🎯 5 分钟快速入门

### 第 1 步：了解整体架构（1 分钟）
查看 **整体架构图**，了解 Skills 的整体结构：

```bash
cat /home/user/skills/docs/images/01-overall-architecture.md
```

**关键点**：
- Skills 分为工程技能和生产力技能两大类
- 每个类别又分为用户调用技能和模型调用技能
- 核心概念包括问题追踪器、问题、分类角色和共享语言

### 第 2 步：安装 Skills（2 分钟）
查看 **安装步骤图**，选择适合的安装方法：

```bash
cat /home/user/skills/docs/images/03-installation-steps.md
```

**推荐安装方式**：
```bash
# 方法1: Claude Code 插件（最简单）
claude plugins install mattpocock-skills

# 方法2: npx skills（灵活）
npx skills@latest add mattpocock/skills
```

### 第 3 步：运行设置命令（1 分钟）
```
/setup-matt-pocock-skills
```

**设置内容**：
- 选择问题追踪器（GitHub Issues、Linear 或本地文件）
- 配置分类标签
- 指定文档存储位置

### 第 4 步：开始使用（1 分钟）
尝试最简单的技能：

```bash
# 询问适合的技能
/ask-matt

# 深入访谈新功能
/grill-me

# 测试驱动开发
/tdd
```

## 🚀 常用技能速查

### 工程技能

| 技能 | 用途 | 使用场景 |
|------|------|----------|
| `/ask-matt` | 询问适合的技能 | 不确定使用哪个技能时 |
| `/grill-with-docs` | 深入访谈 + 文档 | 开始新功能开发前 |
| `/to-spec` | 创建规格说明 | 需求讨论完成后 |
| `/to-tickets` | 分解为问题 | 规格创建后 |
| `/implement` | 实现功能 | 开始编码时 |
| `/tdd` | 测试驱动开发 | 编写新功能时 |
| `/code-review` | 代码审查 | 完成功能后 |

### 生产力技能

| 技能 | 用途 | 使用场景 |
|------|------|----------|
| `/grill-me` | 深入访谈 | 非代码相关的需求 |
| `/handoff` | 交接文档 | 切换工作上下文时 |
| `/teach` | 教学功能 | 学习新技能时 |
| `/wait-what` | 澄清误解 | 沟通不畅时 |

## 🎓 学习路径

### 初学者（第 1 周）
1. 阅读整体架构图，了解全貌
2. 学习安装步骤图，完成安装
3. 查看核心概念图，理解关键概念
4. 尝试 `/grill-me` 和 `/tdd`

### 进阶者（第 2 周）
1. 研究功能对比图，了解所有技能
2. 实践 `/grill-with-docs` 和 `/implement`
3. 尝试 `/code-review` 和 `/improve-codebase-architecture`

### 高级者（第 3 周）
1. 掌握复杂的技能组合
2. 根据项目需求自定义技能
3. 参与社区贡献

## 💡 实用技巧

### 技巧 1：从简单开始
不要一次性学习所有技能，从最简单的开始：
1. `/grill-me` - 学习如何深入访谈
2. `/tdd` - 学习测试驱动开发
3. `/code-review` - 学习代码审查

### 技巧 2：实践为主
理论学习很重要，但实践更重要：
1. 选择一个小项目
2. 使用 Skills 完成整个开发流程
3. 记录遇到的问题和解决方案

### 技巧 3：善用共享语言
共享语言是 Skills 的核心概念之一：
1. 创建项目术语表
2. 使用一致的命名规范
3. 帮助 AI 理解项目上下文

### 技巧 4：定期回顾
定期回顾和改进：
1. 每周回顾使用情况
2. 记录改进点
3. 调整工作流程

## 🔧 常见问题解决

### 问题 1：安装失败
**解决方案**：
- 检查网络连接
- 确认命令正确
- 尝试不同的安装方法

### 问题 2：技能不工作
**解决方案**：
- 确认已运行设置命令
- 检查问题追踪器配置
- 查看技能文档

### 问题 3：AI 不理解项目
**解决方案**：
- 创建共享语言文档
- 使用 `/grill-with-docs` 进行深入访谈
- 提供更多上下文信息
